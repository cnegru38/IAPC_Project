in git bash - from root (you only need to do this part the first time):

ollama pull llama3.2
ollama pull nomic-embed-text
ollama serve (optional)

-- only if you have access to .env --
add .env to resources, right next to application.yaml and pgvector.yml
it's gitignored as per project rule "No secrets in the repository, and configuration is documented."

open docker desktop, make sure it says "Engine running", then run this in terminal:
./mvnw spring-boot:run

*in case it doesn't build and you have to build the database yourself*
in git bash - open from resources:
docker compose -f pgvector.yml up -d

to test if app is running (in git bash - from root):
curl -X POST http://localhost:8080/api/ollama/chat/summarize \
  -H "Content-Type: text/plain" \
  -d "Spring AI is a framework that provides abstractions for working with AI models. It supports chat, embeddings, and vector stores across many providers."

to test if database exists (in git bash - from resources):
docker exec -it pgvector psql -U edupulse -d edupulse -c "\dt"
